# Organigrama del Vault

Mapa visual e interactivo para ubicarse rápido: qué hay en cada sección del vault y cómo fluye el trabajo del curso — de los PDFs de la profesora hasta la Bitácora de aprendizaje. Cada tarjeta es la nota real: haz clic para abrirla directamente.

## 🗺️ Mapa visual (Canvas)

![[Organigrama.canvas]]

> [!tip] Cómo usar el Canvas
> Haz clic en el mapa de arriba para abrirlo a pantalla completa (o abre directamente el archivo `Organigrama.canvas` desde el explorador de archivos, a la par de `Inicio.md`). Ya adentro puedes hacer zoom, mover las tarjetas donde prefieras, agregar tus propias notas sueltas, y hacer clic en cualquier tarjeta para abrir esa nota — los cambios de posición se guardan solos.

## Cómo leer el mapa

- Cada **grupo de color** es una carpeta del vault: dorado para el punto de partida (README · Inicio · Organigrama), azul para `00 Curso`, violeta para `03 Marco Legal`, verde para `02 Unidades`, rosa para `01 Bitácora`, turquesa para referencia y plantillas.
- Las **flechas** entre grupos muestran el ciclo real de trabajo: el marco legal rige los cálculos de cada unidad → la unidad genera sus entregables → esos entregables se registran en la Bitácora → la Bitácora retroalimenta la siguiente entrega (flecha de regreso a la izquierda).
- `Inicio` conecta con `00 Curso` (el punto de partida) y con la sección de referencia — desde ahí sigue la cadena de flechas hacia abajo para ver todo el flujo. Las secciones con más de 3-4 notas (Marco Legal, Unidades) se organizan en varias filas centradas para que el mapa se lea de forma simétrica y ordenada, como un organigrama real.
